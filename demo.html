    AI가 편집·검토 후보를 제안하고, 사람의 승인 후에만 공개합니다.

    02 · 편집과 AI 제안

    원본을 보며 편집하고, AI 초안을 선택합니다

    원본 페이지OCR·회차·표지Claude 제안채택·수정·거절
    • 원본은 덮어쓰지 않음
    • 실제 아동 자료 외부 전송 차단
    • API 키는 서버에만 보관

    편집 결과는 초안이며, 원본·공개본과 분리해 보관합니다.

    03 · 검토와 사람 승인

    위험 후보를 표시하고, 사람이 공개를 승인합니다

    • 개인정보실명·학교·연락처 후보
    • 콘텐츠폭력·위협 표현 후보
    • 저작권직접 만든 작품인지 확인
    • 보호자 동의승인 전 공개 차단

    후보 표시는 자동 판정이 아니며, 운영자·보호자가 원문을 확인합니다.

    05 · 한계와 개선 계획

    현재 한계와 개선 계획

    1. 01
      필터링 범위OCR·문장 규칙 중심이라 그림과 맥락은 확인하지 못함
      원본 육안 검토를 유지하고 비전 분석을 별도 검증
    2. 02
      보호자 승인보호자 계정·동의·철회·승인 이력이 아직 없음
      인증된 동의 절차와 감사 기록 구현
    3. 03
      원격 권한·DB확장 SQL과 역할별 RLS 통합 검증이 끝나지 않음
      migration 적용 후 익명·운영자 권한 시험
    4. 04
      기기 간 동기화가져온 이미지와 일부 초안·댓글은 기기 안에만 저장됨
      비공개 서버 저장과 여러 기기 동시 시험
    5. 05
      실제 자료의 AI 사용Claude 호출은 합성 비민감 문장만 검증함
      학교·보호자 정책 확정 후 제한적으로 활성화

    한계가 해결되기 전에는 사람의 검토와 공개 승인을 유지합니다.
