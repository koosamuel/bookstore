01 · 문제와 사용자

사용자

  • 보호자 · 동의
  • 운영자 · 편집·검토
  • 독자 · 승인본 열람

AI가 대신 쓰는 책이 아니라, 어린이의 책을 안전하게 소개하는 과정입니다.

02 · 기존과 개선

수작업을 없애지 않고, 확인하기 쉽게

기존
  • 사진을 따로 정렬
  • 소개문을 다시 작성
  • 검토 기록이 흩어짐

개선
  • 페이지 내비게이터·자르기

  • 승인 전 공개 차단

자동화의 목적은 창작 대체가 아니라 반복 작업과 누락을 줄이는 것입니다.

03 · 시스템과 데이터 경계

초안·검토·공개를 분리합니다

기기원본 확인·페이지 편집카메라·앨범 이미지는 먼저 기기 초안으로 보관
→
Supabase로그인·대본·검토 상태운영자 권한과 RLS로 비공개 작업 보호
→
공개 서점승인된 결과만 열람공개본과 비공개 원본의 접근 경로 분리

API 비밀키는 브라우저에 두지 않고, 확인한 문장만 서버 함수가 처리합니다.

04 · 편집 기능

한 화면에서 페이지와 회차를 정리합니다

  1. 01카메라·앨범에서 가져오기
  2. 02순서·최종 표시 영역 조절
  3. 03회차·제목·표지 지정
  4. 04확인 문장·대본 저장

왼쪽 전체 이미지 내비게이터에서 고르고, 큰 원본을 보며 오른쪽에서 편집합니다.

05 · AI와 사람 검토

AI는 원문을 바꾸지 않고 제안만 합니다

OCR·확인 문장운영자 확인 + 전송 동의Claude 선택 제안
  • 원문은 별도 보존
  • 최대 5개 제안
  • 채택·수정·거절은 사람

이미지·작가 정보는 보내지 않으며, 개인정보 후보가 있으면 서버에서 먼저 차단합니다.

06 · 안전 승인

자동 판정 대신 ‘확인 후보’를 보여 줍니다

  • 개인정보실명·학교·연락처 후보
  • 콘텐츠폭력·위협 표현 후보
  • 저작권직접 만든 작품인지 확인
  • 보호자 동의승인 전 공개 차단

OCR 누락과 그림 속 장면은 사람이 원본을 보고 최종 판단합니다.
